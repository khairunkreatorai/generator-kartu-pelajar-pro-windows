# Generator Kartu Pelajar Pro Windows Launcher

Generator Kartu Pelajar Pro is a Windows application that provides an easy-to-use launcher for the **Generator Kartu Pelajar Pro** student ID card generator system.

## About

This launcher opens the online website **Generator Kartu Pelajar Pro** directly from your Windows desktop. It provides quick access to the web-based application without needing to manually open a browser and navigate to the website.

## Requirements

- **Windows OS**: This launcher is designed to run on Windows operating systems.
- **Internet Connection**: An active internet connection is required to use this application, as it opens the online website and relies on server-side functionality.

## Warning: Windows SmartScreen

When you first run this application, Windows SmartScreen may display a warning because the executable is **unsigned**. This is normal for newly released or unsigned software. You can safely proceed by clicking "More info" and then "Run anyway" if you trust the source.
